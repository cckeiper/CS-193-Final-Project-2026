# Sweet Sisters Matching Game
The Sweet Sisters Princess Parties Matching Game allows more interaction for children in
their website.


## The Problem
The Sweet Sisters Princess Parties Website needs more features to attract customers while also staying easy to navigate. Customers who feel more informed by another party provider might give their business to them. I hope that by adding this, our business will continue to thrive and grow.


## How It Works
- Flip cards with icons
- Match Detection
- Win/Lose Prize

![System flowchart](docs/CS%20193%20Final%20Project.png)


## Tech Stack
- [Sweet Sisters Website](https://ssprincessparties.com/) is the original website
- Languages: HTML, JavaScript, CSS
- Resources: Git, GitHub 
- Local: VS Code IDE, Chrome browser (debug)
- Data Sources: Card list in JavaScript
- Data Storage: None for MVP
- Libraries: Animation (flip-card), Win Condition (canvas-confetti)
- Card Icons: made in Canva


## Usage
How to play:
- Click to flip cards
- Find cards with matching icons
- Win once all the cards are matched
